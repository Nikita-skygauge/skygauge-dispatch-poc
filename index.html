Connect Google Maps

This POC renders the Dofasco works in Google's photorealistic 3D. It needs a Maps JavaScript API key, stored only in this browser — never in the page file.

  1. Google Cloud Console → create a project → enable billing (the monthly free credit covers a demo).
  2. APIs & Services → Library → enable Maps JavaScript API.
  3. Credentials → Create API key. Restrict it: Application restrictions → Websites → add the domain you host this file on (e.g. https://your-site.netlify.app/*). API restrictions → Maps JavaScript API only.
  4. Paste the key below.
